## Session

| Method | Returns | |
| --- | --- | --- |
| `init(config)` | `TrackResponse \| null` | Start a session and send the automatic signals once |
| `getSession()` | `SessionResponse` | Current session and inferred personas |
| `getSessionId()` | `string` | The current session id |
| `resetSession()` | `void` | Clear it and start fresh |
| `onPersona(cb)` | `void` | Subscribe to persona updates |

## Signals and ranking

| Method | Returns | |
| --- | --- | --- |
| `track(signals)` | `TrackResponse` | Send shopper signals |
| `search(products, options?)` | `SearchResponse` | Rank products you pass in |
| `rankedCatalog(options?)` | `RankedCatalogResponse` | Rank the catalogue already synced to PULSE |
| `event(type, data?)` | `EventResponse` | Record a named event |

<Callout>
  `search` and `rankedCatalog` are not interchangeable. `search` ranks what you hand it;
  `rankedCatalog` ranks what PULSE already holds.
</Callout>

## Exposure

| Method | | |
| --- | --- | --- |
| `exposure(decisionId, items)` | `void` | Record what was actually rendered, buffered |
| `flushExposures()` | `Promise<void>` | Send buffered exposures now |
