**Open Pulse** ([github.com/mypulseapi/open-pulse](https://github.com/mypulseapi/open-pulse)) is the
open-source half of PULSE. PULSE is a decision call: requirements and evidence in, and for every
option a verdict out, **fits, fails or cannot tell, with what is missing**. It works in any industry
where options have attributes, products, suppliers, hotels, plans, and it is built for AI agents
such as Claude, ChatGPT, Claude Code and Codex as much as for your own code.

The client code is open, so you can read exactly what runs on your machine or your site. The
decision engine runs behind the [API](/api).

```js
// Which suppliers meet the spec? Any domain: "products" is just the list of options.
await fetch("https://api.thepulseapi.com/api/v1/decide", {
  method: "POST",
  headers: { "content-type": "application/json", "x-api-key": "pk_live_..." },
  body: JSON.stringify({
    requirements: [{ attribute: "ip_rating", op: "eq", value: "IP67" }],
    products: [
      { id: "acme", attributes: { ip_rating: "IP67" } },
      { id: "corvid", attributes: {} },
    ],
  }),
});
// acme fits · corvid cannot_tell, missing ip_rating
```

The repository has runnable examples for developers and agents, an `AGENTS.md` for coding agents,
and a comparison with typed-decision models such as Jev.

## What is released

| Package | What it is | Status | Source |
| --- | --- | --- | --- |
| `@thepulseapi/sdk` | The browser SDK: signals, ranking, measurement. About 3 KB on the CDN | **On npm**, 0.2.0, MIT | [`mypulseapi/open-pulse`](https://github.com/mypulseapi/open-pulse/tree/main/packages/sdk) |
| `@thepulseapi/mcp` | MCP server: search these docs, and with a key, [`resolve_products`](/mcp) | **On npm**, 0.2.0, MIT | [`mypulseapi/open-pulse`](https://github.com/mypulseapi/open-pulse/tree/main/packages/mcp) |

```bash
npm install @thepulseapi/sdk
```

For an agent, add the MCP server to your client ([MCP for agents](/mcp) has the config):

```bash
npx -y @thepulseapi/mcp
```

## What stays behind the API

Ranking and prioritisation, Decision Verification, the Promotion Audit's noise checks and
economics, and anything learned from customers' data, which is never published. Open code finds
problems; the API decides what is worth fixing.

## How to contribute

1. **Open an issue first** on [GitHub](https://github.com/mypulseapi/open-pulse/issues): a bug, a
   language the parser misreads, an adapter you need.
2. **Then a pull request**, small and with a test. Contribution terms are being finalised; we will
   publish them before accepting larger changes.
