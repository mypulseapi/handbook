Client là TypeScript thuần, không có phụ thuộc lúc chạy và không gắn với framework nào. Mọi API trình
duyệt mà nó dùng đều nằm sau một phép kiểm tra `typeof`, nên import nó khi render phía máy chủ là an
toàn. Chỉ `init()` cần trình duyệt.
