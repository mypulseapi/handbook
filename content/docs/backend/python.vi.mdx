Hoặc `requests`, nếu dự án đã có sẵn. Cả hai đều dùng được; `httpx` được chọn ở đây vì nó có client
async mà FastAPI cần mà không phải thêm phụ thuộc thứ hai.

## Một client

```python title="pulse.py"
import os
import httpx

BASE = "https://api.thepulseapi.com/api/v1"


class Pulse:
    """Thin wrapper over the HTTP API. Every call is POST and returns JSON."""

    def __init__(self, api_key: str, organization_id: str, timeout: float = 5.0):
        self._org = organization_id
        self._client = httpx.Client(
            base_url=BASE,
            timeout=timeout,
            headers={"x-api-key": api_key, "Content-Type": "application/json"},
        )

    def _post(self, path: str, body: dict) -> dict:
        # organizationId is required on nearly every endpoint and is read from the body,
        # not from the key, so it is filled in here rather than at every call site.
        response = self._client.post(path, json={"organizationId": self._org, **body})
        response.raise_for_status()
        return response.json()

    def track(self, session_id: str, signals: list[dict]) -> dict:
        return self._post("/track", {"sessionId": session_id, "signals": signals})

    def session(self, session_id: str) -> dict:
        # /session takes only sessionId. Sending organizationId is harmless.
        return self._post("/session", {"sessionId": session_id})

    def ranked_catalog(self, session_id: str, limit: int = 24, **kwargs) -> dict:
        return self._post(
            "/catalog/ranked", {"sessionId": session_id, "limit": limit, **kwargs}
        )


pulse = Pulse(os.environ["PULSE_API_KEY"], os.environ["PULSE_ORG_ID"])
```

```python
pulse.track("sess_abc123", [{"type": "category_view", "value": "helmets-safety"}])
ranked = pulse.ranked_catalog("sess_abc123", limit=24)
```

## Django

Tạo client một lần ở cấp module, không tạo theo từng yêu cầu. `httpx.Client` giữ một nhóm kết nối, và
tạo mới cho mỗi view sẽ bỏ phí điều đó.

```python title="catalog/views.py"
from django.shortcuts import render
from .pulse import pulse


def category(request, slug):
    # The browser owns the session. Read it rather than minting a second one for the
    # same shopper: two session ids means the inference starts from nothing twice.
    session_id = request.COOKIES.get("pulse_session")
    products = []

    if session_id:
        try:
            products = pulse.ranked_catalog(session_id, limit=24, categorySlug=slug)["items"]
        except Exception:
            # Ranking is an enhancement. A page that fails to render because personalisation
            # was slow is worse than a page in catalogue order.
            products = []

    return render(request, "category.html", {"products": products or default_order(slug)})
```

## FastAPI

Dùng client async, và giữ nó trên app để nó được tạo một lần và đóng khi tắt ứng dụng.

```python title="main.py"
import os
from contextlib import asynccontextmanager

import httpx
from fastapi import FastAPI

BASE = "https://api.thepulseapi.com/api/v1"
ORG = os.environ["PULSE_ORG_ID"]


@asynccontextmanager
async def lifespan(app: FastAPI):
    app.state.pulse = httpx.AsyncClient(
        base_url=BASE,
        timeout=5.0,
        headers={"x-api-key": os.environ["PULSE_API_KEY"]},
    )
    yield
    await app.state.pulse.aclose()


app = FastAPI(lifespan=lifespan)


@app.get("/ranked/{session_id}")
async def ranked(session_id: str, limit: int = 24):
    response = await app.state.pulse.post(
        "/catalog/ranked",
        json={"sessionId": session_id, "organizationId": ORG, "limit": limit},
    )
    response.raise_for_status()
    return response.json()
```

<Callout type="warn" title="Đặt timeout cho nó">
  Cả `requests` lẫn `httpx` đều không có timeout mặc định theo cách đa số mọi người nghĩ. Một lệnh xếp
  hạng bị treo sẽ giữ một worker cho tới khi thứ khác chịu thua. Năm giây là rộng rãi; lệnh gọi thường
  chỉ mất vài chục mili giây.
</Callout>
